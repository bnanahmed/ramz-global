## 🚀 التشغيل السريع

### الطريقة الأولى (الأسهل):
1. اضغط مرتين على ملف `install_and_run.bat`
2. سيقوم الملف بتثبيت الحزم وتشغيل الموقع أوتوماتيكياً.

### الطريقة الثانية (يدوي):
```bash
npm install
npm run dev
```

## 🌐 رفع الموقع على Vercel
يمكنك رفع الموقع بضغطة زر عبر ملف `deploy_vercel.bat`.
